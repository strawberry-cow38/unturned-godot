# Item text audit — 2026-09-04

strawberry: *"run through every item's description and make sure its true, relevant, works with our
systems. as well as proper formatting, color tags. mark anything we are missing gameplay wise. make guns
say their caliber"*.

1,944 items in `content/items_catalog.tsv`. Checked against what the code actually does, not against
retail — "true" means true *here*.

## Fixed in this pass

**Guns name their real cartridge.** 45 rewritten, 13 already correct, 3 have no caliber. Retail names the
round after the gun ("chambered in Timberwolf ammunition"), which tells a player nothing they can act on.
The `.dat` has carried `Caliber_Name` all along. Applied as a load-time overlay in `ItemCatalog`
(`NameTheCaliber`), NOT by editing the .tsv — the .tsv is generated by `tools/gen_item_catalog.py` from a
Windows Steam install, so it cannot be regenerated here and a hand-edit would be silently reverted by the
next run. Same reasoning as the existing `PlayerDamageByCaliber` overlay.

Two real content errors fell out of it:
- **The Crossbow said it fires arrows.** Its caliber is `Bolt`. Bows, the Rocket Launcher and the
  Paintball Gun were all fine — their singular caliber is a substring of the plural already in the text.
- **The Avenger's hand-written override** (`Text(1021)`) ran after the caliber pass and put retail's text
  back. Now reads `.45 ACP`, which makes its point — that it shares the 1911's round — better than the
  old text did.

Covered by `gun.description_names_caliber` (9 checks), including a sweep over every ported gun so one
added later with retail text fails here instead of shipping. Teeth verified: disabling the overlay and
removing the already-named guard each turn it red.

## Found, NOT fixed — needs a decision

### 1. Colour tags do not render. 59 items affected.
`<color=legendary>Timberwolf</color>` is Unity rich text. Both description widgets are a plain `Label`
(`InventoryUI.cs:1328`, `CraftingMenu.cs:480`) — there is no `RichTextLabel` anywhere in the inventory
and nothing strips or converts the tags at load. **The player sees the literal angle brackets.**
Fix is small and self-contained: convert `<color=<rarity>>` to Godot BBCode using the per-rarity colours
`ItemTool.RarityColorUI` already provides, and render in a `RichTextLabel`. Not done here because it is a
UI change rather than a text one, and worth doing deliberately.

### 2. 656 items show an INTERNAL name. A third of the catalog.
`Tuxedo_Bottom_Gold`, `Festive_Hat`, `Mystery_Box_0`, `Honeybadger_Barrel`, `Key_0`. Cause is
`gen_item_catalog.py:42` — `name = eng.get('Name') or os.path.splitext(fn)[0]` — so any item whose
`English.dat` lacks a `Name` (or is missing) gets its FILENAME. Mostly cosmetics (177 shirts, 125 hats,
105 pants) but includes 23 boxes, 16 keys, 7 barrels, 1 sight and 1 gun.
This is a rip gap, not a code bug: fixing it means re-ripping those `English.dat` files on the Windows
box. Worth doing before anyone sees a "Mystery_Box_3" in their inventory.

### 3. 773 items have no description; 52 of them are functional.
721 are cosmetics, which retail largely leaves blank too — low value. The 52 that matter:
`Box 24, Key 17, Barrel 7, Storage 2, Sight 1, Gun 1`. Same rip gap as above, same fix.

## Checked and genuinely fine — not padding

- **Consumables are honest.** Cross-checked all 165 rows of `consumable_stats.tsv` against their
  descriptions. Zero items claim an effect they do not have. Only 2 are inert (`Heatstim`, `Chewing Gum`),
  and both read as deliberate flavour rather than a missing effect. Three items have an effect the text
  never mentions (Medkit stops bleeding and heals bones, Suturekit stops bleeding) — worth adding, but
  the text is not *wrong*.
- **The survival stats claimed in text all exist**: Health, Food, Water, Stamina, Infection, Bleeding,
  broken bones. My first pass grepped for "Hunger"/"Thirst", got zero, and nearly filed a false finding —
  they are named `Food` and `Water`.
- **"Warm weather tee" / "Chilly weather hoodie"** (55 items) are not lying about a temperature system we
  lack; they describe the garment. Left alone.
- **The 46 reused descriptions** (`"Rail mounted iron sights."` ×34) are genuinely identical items.
